# Clan Chaos — Product Overview

Clan Chaos is a 2–8 player real-time multiplayer strategy and deception game that runs in the browser. Each player leads a rival clan on a shared, illustrated fantasy map. Players gather resources with travelling parties, fortify their strongholds, buy tactical cards, trade, negotiate, and send **secret raids** that are revealed at the same time at the end of each round.

- **Players:** 2–8, each on their own phone or computer.
- **Identity:** a guest name plus a six-character room code. There are no accounts. A secret reconnect token, stored in the browser, lets a player rejoin the same clan.
- **Length:** 8 rounds of 75 seconds each (about 10 minutes), plus 3 public random events.
- **Tone:** chaotic, humorous and backstabby. Promises are never enforced.
- **Targets:** local development and play over a LAN or shared Wi-Fi. The backend is self-hosted Node.js + PostgreSQL, with no cloud services.
- **Art:** all original inline SVG and emoji. No remote images or copyrighted assets.
